# Cursor Schedule

A modern schedule-tracking app inspired by Motion, Morgen, Sunsama, Akiflow,
Todoist, Microsoft Planner, and Notion Calendar.

The app focuses on a calm daily agenda where tasks, events, reminders, and
personal items share one timestamped timeline. It includes fast capture,
drag-and-drop time blocking, smart filters, priority and recurrence fields,
detail editing, local persistence, and a weekly review queue for unfinished
items.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to use the planner.

## Scripts

- `npm run dev` - start the local development server
- `npm run build` - create a production build
- `npm run lint` - run ESLint
- `npm run typecheck` - run TypeScript checks
